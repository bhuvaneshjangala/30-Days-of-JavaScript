# 30 Days of JavaScript - LeetCode

Repository for a 30-day challenge solving JavaScript problems from LeetCode. Each folder groups related problems (closures, array transforms, function utilities, promises/time utilities, JSON helpers, and class-based patterns).

## Topics Covered
- Closures and higher-order functions
- Array transformations and functional patterns
- Function utilities (composition, memoization, argument handling)
- Promises, async timing, debouncing, throttling, and caching
- JSON and data manipulation helpers
- Classes, event emitters, and method chaining

## Folder Structure
- `Closures`: closure-based problems and utilities
- `Basic_Array_Transformations`: map/filter/reduce style problems
- `Function_Transformations`: function composition, memoize, etc.
- `Promises_And_Time`: async utilities, timers, cancellations
- `JSON`: object/array helpers and data transformations
- `Classes`: class-based implementations and patterns

## Goal
The goal is to implement each LeetCode problem in JavaScript, include a clear problem header template in every file, and organize solutions by topic to build a comprehensive reference for common JS interview and algorithmic patterns.

## Usage
- Implement solutions in the corresponding files.
- Run Node.js to test individual files as needed.

Contributions are welcome — open issues or pull requests to suggest improvements or add solutions.
